# Student Management System (SMS)

A robust, secure, and responsive web-based application engineered to automate student profiling, continuous assessment grading, GPA calculation, and dynamic attendance tracking. 

## 🚀 Core Features
* **Secure Authentication:** Session-guarded administrator access dashboard.
* **Unified Intake Registry:** Complete student enrollment with secure file/photo uploads.
* **Algorithmic GPA Calculation:** Automatic score-to-grade mapping and cumulative GPA processing in real-time.
* **Digital Attendance Tracker:** Daily classroom tracking logs with calculated percentage aggregates.
* **On-Demand PDF Reports:** Generation of stable, structured institutional progress reports with automatic date-and-time timestamps.
* **Security Measures:** Hardened with Prepared Statements to mitigate SQL Injections and file-type verification for uploads.

## 🛠️ Technology Stack
* **Backend:** PHP 8.0+
* **Database:** MySQL / MariaDB 10.4+
* **Environment:** Apache via XAMPP
* **Platform:** Ubuntu Linux 20.04+ LTS
* **Frontend:** Custom HTML5, CSS3 (100% Mobile Responsive)
